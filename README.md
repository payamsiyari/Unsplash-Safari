# Unsplash-Safari
A super simple HTML file for having random background wallpapers in Safari, and pretty much any other browser (Desktop or Mobile).

> **Note**: Following the sunset of `source.unsplash.com` in 2023, the background image source was updated to use [Picsum Photos](https://picsum.photos/) (`https://picsum.photos/3200/1600`) for high-resolution random wallpapers. The project name is kept as *Unsplash-Safari* for historical context. (Special thanks to [@alexandreleroux](https://github.com/alexandreleroux) for suggesting this replacement).

## Installation
* All needed to be done is to point the homepage of the browser to the location of `unsplash.html` file.
